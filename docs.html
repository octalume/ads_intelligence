AI Platform Quickstart

OctaLume is engineered to run in parallel with your LLM inference call. While your model streams tokens to the user, OctaLume evaluates commercial intent in under 45ms and returns a native sponsored card ready to render inline or below the response.

1. Install SDK
npm i @octalume/sdk
2. Call Parallel
Pass user prompt context alongside LLM request
3. Render & Earn
Display SponsoredCard with auto-impression tracking

Publisher SDKs

Choose your server or client runtime. React components include built-in IntersectionObserver viewport impression tracking.

@octalume/sdk (TypeScript)
import { OctaLume } from '@octalume/sdk';

const client = new OctaLume({ apiKey: process.env.OCTALUME_API_KEY });

// Run in parallel with your LLM stream — zero added latency
const [llmStream, adResponse] = await Promise.all([
  openai.chat.completions.create({ model: 'gpt-5', messages, stream: true }),
  client.ads.place({
    context: messages[messages.length - 1].content,
    publisherId: 'my-ai-chat',
    placement: 'inline_response',
    maxAds: 1,
  }),
]);

Ad Serving HTTP API

POST /v1/ads/place

Direct backend-to-server endpoint for custom AI agents, search engines, or non-JS runtimes.

cURL — Request Native Ad
curl -X POST https://api.octalume.io/v1/ads/place \
  -H "Authorization: Bearer oct_pub_live_..." \
  -H "Content-Type: application/json" \
  -d '{
    "context": "Best CRM for a 15-person B2B sales team",
    "publisher_id": "perplexity-sonar",
    "placement": "inline_response",
    "consent": { "gdpr": true, "gpc": false }
  }'
PRIVACY & PLACEMENTS

Placements & Consent Compliance

Supported Placements

Use above_response, inline_response, below_response, or search_result to match your chat UI.

GDPR & GPC Handling

When user consent is omitted or GPC is enabled, OctaLume automatically serves contextual-only ads with zero user identifiers stored.
